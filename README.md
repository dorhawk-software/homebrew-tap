# dorhawk.software's Homebrew tap

Mac apps by [dorhawk.software](https://dorhawk.software), for Homebrew.

```sh
brew install --cask dorhawk-software/tap/crake
```

| Cask | |
|---|---|
| `crake` | [Crake](https://dorhawk.software/crake/): your VPN, only where it's needed. Installs Homebrew's `openconnect` with it. |

The casks are updated by each app's release workflow; please report problems in the app's own
repository.
